# J.S. Vespera Website mit Browser-Admin

## Wichtig
Diese Version ist für Netlify + Decap CMS vorbereitet. Die öffentliche Website bleibt deine Website. Die Bearbeitung erfolgt später direkt im Browser über:

https://DEINE-SEITE.netlify.app/admin/

## Einmalige Einrichtung
1. Lege ein GitHub-Repository an und lade den gesamten Inhalt dieses Ordners hoch.
2. In Netlify: Add new project / Import an existing project / GitHub wählen / Repository verbinden.
3. Deploy.
4. In Netlify: Project configuration -> Identity -> Enable Identity.
5. Registration preferences: Invite only.
6. Unter Identity -> Services: Enable Git Gateway.
7. Dich selbst als Identity-Nutzerin einladen und die E-Mail-Einladung bestätigen.
8. Öffne danach https://DEINE-SEITE.netlify.app/admin/

Danach bearbeitest du die Website über /admin und klickst auf Speichern/Veröffentlichen. Decap schreibt die Änderungen in das Repository; Netlify veröffentlicht die neue Version automatisch.

## Bearbeitbar im Admin
- Startseite und Hero-Bild
- Über mich und Foto
- Deadly Words: Geschichte, Echtheit, Triggerliste, Cover
- Testleser-Texte
- Blogger & Kooperationen
- Kontakt
- Instagram/TikTok
- Impressum/Datenschutz
- Weitere Bücher mit Cover, Klappentext, Triggerliste und eigener Detailseite

Die alte lokale Bearbeiten-Funktion wurde auf der öffentlichen Website ausgeblendet. Sie war nur Browser-Speicher und ist nicht mehr der Veröffentlichungsweg.
