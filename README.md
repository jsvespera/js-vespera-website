# J. S. Vespera – Offizielle Website & CMS

Diese Repository enthält den Quellcode für die offizielle Website von **J. S. Vespera**, inklusive des integrierten **Decap CMS** Admin-Bereichs.

## 🚀 Status & Hosting
- **Hosting:** Vercel
- **CMS:** Decap CMS (über Git Gateway / GitHub OAuth)
- **Domain:** [jsvespera.de](https://jsvespera.de)
- **Admin-Panel:** [jsvespera.de/admin](https://jsvespera.de/admin)

---

## 🛠️ Verwaltung im Browser (/admin)

Über das Admin-Panel können folgende Bereiche der Website ohne Code-Kenntnisse bearbeitet werden:

- **Startseite & Hero-Bereich**
- **Über mich & Autorinnen-Profil**
- **Deadly Words – Jedes Wort eine Lüge** (Klappentext, Details, Triggerwarnungen, Cover)
- **Testleser-Informationen & Feedback**
- **Blogger & Kooperationsanfragen**
- **Social Media & Kontakt** (Instagram, TikTok)
- **Impressum & Datenschutz**

---

## 📌 Hinweis zur Technik
Änderungen, die im Admin-Bereich (`/admin`) gespeichert werden, schreibt Decap CMS direkt als Commits in dieses GitHub-Repository. Vercel führt anschließend automatisch ein neues Deployment der Live-Website durch.
